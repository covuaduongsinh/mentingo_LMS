Bảng xếp hạng đội **pull-based** giống nguyên lý tiebreak L6 — tính lại từ `chess_broadcast_games.result` mỗi lần gọi. Cron kéo PGN tự động (`ChessBroadcastCron`, mẫu `ChessMatchCron` L4) chỉ áp dụng cho bàn có `pgnSourceUrl` **và** buổi tường thuật đang `live`; hàm fetch (`safe-pgn-fetch.ts` + `ssrf-guard.ts`) là bản **nhân bản đầy đủ** của `link-preview/utils/safe-fetch.ts` (không import chung — đúng tiền lệ đã lặp lại từ webhook module ở Đợt 9 LearnHouse), chỉ đổi "trích OG-tag HTML" thành "coi cả response là văn bản PGN thô". **2 bug thật phát hiện qua smoke test thủ công qua Caddy** (không lộ qua tsc/eslint/jest vì test đơn vị mock repository): (1) quên set `mode: "string"` trên 3 cột timestamp mới (`startsAt`/`lastFetchedAt`/`ingestedAt`) — **mọi** cột timestamp khác trong toàn bộ schema đều set tường minh `mode: "string"`; thiếu nó khiến drizzle trả `Date` object thay vì string, vỡ response validation TypeBox (`Type.String()`) ngay khi có nước đi thật, và làm sai lệch phép so sánh `<=` giữa string/Date (Date bị ép về string theo `toString()` mặc định, không phải ISO, so sánh trở thành vô nghĩa) — sửa cả schema (`storage/schema/index.ts`) và chỗ so sánh (`new Date(move.ingestedAt) <= cutoff`).

# Quy định dự án cho Claude Code

## Lệnh thường dùng

- Build: `npm run build`
- Test: `npm run test`
- Dev server: `npm run dev`

## Code Style & Quy tắc

- Ngôn ngữ: Vietnamese khi giao tiếp với tôi.
- Luôn kiểm tra `git status` trước khi sửa nhiều file.
- Viết code ngắn gọn, chuẩn TypeScript/JavaScript.
